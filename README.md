# 沧月 · 写作风格 Skill

一个用于 WorkBuddy 的**写作风格工具**：仿写、续写、改稿、审稿。
它能按沧月（《镜》《听雪楼》《七夜雪》作者）的文风生成文本，也能用她的美学标准评判文本——**不是角色扮演，不模拟她本人说话**。

## 能做什么

- **仿写 / 续写**：按「中期风格」「早期风格」等档位生成场景片段
- **改稿**：把"AI 味"或通用古风腔改成沧月式的句子与节奏
- **审稿**：10 条审稿清单逐条判定，前 3 条一票否决
- **命名**：生成符合她命名习惯的人名、章节名
- **知边界**：遇到她没有写过的题材（如现代都市），先声明"这是推断"再动笔

## 五个文风内核

| 内核 | 一句话 |
| --- | --- |
| 反差即痛感 | 先把景写到极净极亮，再让死亡落进来，最后让无情之物继续美 |
| 句号即剪辑 | 用标点完成转场："十四年以后。／洛阳。朱雀大道。听雪楼。" |
| 半文半白，四字为骨 | 白话底子，情绪上来嵌一两句文言；一段只放一组对偶 |
| 时间升格 | 不写"明天"，写一生、百年、千年；最终施暴者是时间 |
| 瓶子论 | 世界观为情感服务——判断设定去留只问：它让谁的"守护／放弃"更疼 |

另含：三时期选择器（早期"宁为玉碎"／中期"妥协钝痛"／后期收敛议论）、三节连缀的篇级骨架、10 条反模式。

## 安装

把本仓库的全部内容放到 `~/.workbuddy/skills/cang-yue-perspective/`，使 `SKILL.md` 位于该目录根下：

```
~/.workbuddy/skills/cang-yue-perspective/
├── SKILL.md
├── README.md
└── references/
    ├── voice.md
    ├── casebook.md
    ├── validation.md
    └── research/

        ├── 02-conversations.md
        ├── 03-expression-dna.md
```

新开一个会话后即可被调用。Windows 路径为 `C:\Users\<你的用户名>\.workbuddy\skills\cang-yue-perspective\`。

## 用法示例

```
用沧月的笔法写一段：剑客在雪夜等一个不会来的人
这段像不像沧月？帮我把 AI 味改掉
沧月会怎么改这个开篇
帮我起几个沧月味的人名和章节名
```

## 文件说明

- `SKILL.md`：技能主体，包含全部可运行规则
- `references/voice.md`：原话库，防止编造她的语录
- `references/casebook.md`：15 组原文案例与逐句技术拆解
- `references/validation.md`：独立盲测报告（初评 72/100）与修复记录
- `references/research/`：5 路调研底稿，逐条标注来源与可信度

## 事实校正（重要）

1. **"沧月＝BE 专业户"不成立**：悲剧性集中在 2012 年以前，后期明显衰减，她 2016 年宣布转写 HE。
2. **"宿命"是评论者的词**：她本人只用它形容"书写是我的宿命"，从未用它概括作品主题。
3. **《七夜雪》题记诗不是她原创**：系化用席慕蓉同题诗，Skill 中只称"书中题记"。

## 来源与边界

调研基于公开资料：作品原文、作者序跋与后记、媒体访谈、文学评论。不收录未经核实的所谓"沧月语录"，查不到出处的片段会明确标注。本 Skill 仅供学习与写作练习，原作品版权归作者所有。
